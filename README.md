# C - Binary Trees

## Description

This project focuses on implementing and manipulating Binary Trees using the C programming language. The project covers the fundamentals of binary trees, including node creation, insertion, deletion, traversal methods, measurements, and property checks.

The goal of this project is to strengthen understanding of:
- Dynamic memory allocation
- Structures and pointers
- Recursion
- Tree traversal algorithms
- Binary tree properties and relationships

---

# Learning Objectives

By completing this project, we learned how to:

- Create and manipulate binary tree nodes
- Traverse binary trees using different traversal methods
- Measure height, depth, size, and balance of trees
- Identify leaves, roots, siblings, and uncles
- Determine whether a binary tree is full or perfect
- Use recursion efficiently in tree-based problems
